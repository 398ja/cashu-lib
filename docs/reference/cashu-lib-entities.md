# cashu-lib-entities

Data transfer objects and annotations for Cashu REST APIs.

- **Packages**:
  - `xyz.tcheeric.cashu.entities.annotation`
  - `xyz.tcheeric.cashu.entities.rest`
- **Primary classes**:
  - `Nut` and `Supports`
  - REST DTOs like `PostMintRequest`, `PostMeltResponse`, `PostSwapRequest`
- **Javadoc**: [cashu-lib-entities API Reference](https://javadoc.io/doc/xyz.tcheeric/cashu-lib-entities)
